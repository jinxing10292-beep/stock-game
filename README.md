# 📈 모의 주식 게임

HTML, CSS, JavaScript로 만든 브라우저 기반 모의 주식 거래 게임입니다. 로컬 스토리지를 사용하여 각 디바이스에서 게임 데이터를 저장하고 관리합니다.

## 🎮 기능

- **주식 추가/삭제**: 커스텀 주식을 추가하고 관리
- **매수/매도**: 실시간 주가로 주식 거래
- **포트폴리오 추적**: 보유 주식의 평단가, 손익률 확인
- **자산 현황**: 총 자산, 현금 잔액, 수익률 실시간 업데이트
- **로컬 스토리지 저장**: 브라우저를 종료해도 데이터 보존
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 모두 지원

## 🚀 시작하기

### 설치 (설치 불필요!)
별도의 설치나 빌드 과정이 필요 없습니다. 즉시 사용 가능합니다.

### 사용 방법

1. `index.html` 파일을 웹 브라우저에서 열기
2. 주식을 추가하기 (이름, 종목코드, 현재가)
3. 주식 카드에서 "거래" 버튼을 눌러 매수/매도
4. 포트폴리오에서 손익 현황 확인

## 📊 게임 구조

### 초기 자금
- **₩1,000,000** (1백만원)

### 주식 정보 입력 항목
| 항목 | 설명 |
|------|------|
| 주식 이름 | 회사명 (예: Apple) |
| 종목코드 | 티커 심볼 (예: AAPL) |
| 현재가격 | 주식의 현재 거래가 |

### 포트폴리오 정보
- **보유량**: 해당 주식의 보유 수량
- **평단가**: 보유 주식의 평균 매입가
- **투자금**: 해당 주식에 투자한 총액
- **현재가치**: 현재 시점의 주식 총 가치
- **손익**: 실현/미실현 손익 및 수익률

## 💾 데이터 저장

모든 게임 데이터는 브라우저의 **로컬 스토리지**에 저장됩니다.
- 데이터 위치: `localStorage['stockGameData']`
- 동기화: 거래할 때마다 자동 저장
- 초기화: "게임 리셋" 버튼으로 모든 데이터 삭제

## 🛠️ 기술 스택

- **HTML5**: 시맨틱 마크업
- **CSS3**: 그리드 레이아웃, 플렉스박스, 애니메이션
- **JavaScript (ES6+)**:
  - 클래스 기반 구조
  - 로컬 스토리지 API
  - 이벤트 리스너 기반 UI 업데이트

## 📱 지원 환경

- Chrome, Firefox, Safari, Edge 최신 버전
- 반응형 디자인으로 모든 화면 크기 지원
- 모바일 터치 지원

## 📝 주요 기능 설명

### 주식 추가
- 추가하려는 주식의 정보 입력
- 실시간 가격 입력 가능
- 중복된 종목코드 입력 불가

### 거래 (매수/매도)
- 수량 입력 후 매수/매도 실행
- 보유 자금 부족 시 거래 불가
- 매도는 보유 수량 범위 내에서만 가능

### 포트폴리오 관리
- 보유 주식별 수익/손실 실시간 계산
- 평단가를 기반으로 손익률 표시
- 모든 주식 보유량 0이 되면 포트폴리오에서 제거

## 🎯 게임 플레이 팁

1. **다양한 주식 추가**: 실제 주식들을 추가해서 거래해보세요
2. **시세 변동**: 시간이 지나면서 주가를 수정하여 변동성 반영
3. **손익 분석**: 포트폴리오에서 각 종목의 수익률 비교
4. **포트폴리오 리밸런싱**: 주기적으로 포트폴리오 점검 및 조정
